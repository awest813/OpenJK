OpenJK

Star Wars Jedi Knight: Jedi Academy, in the browser, using your own copy of the game. Pick a mode. Both share the game data you add on the next page.

Single playerOpen The Jedi Academy campaign. MultiplayerOpen Bots on this machine, or other servers through this site's relay. Rend2Open Multiplayer with the rend2 renderer. Same game data, a different picture. Experimental.

You'll add the .pk3 files from your Jedi Academy install on the next page. They stay in this browser.

OpenJK is open source and not affiliated with Raven Software, Activision or Lucasfilm. Game data is never uploaded.
